# Model licences and costs

**Status: NOT independently re-verified in this build.** The details below come from the public model cards the catalogue entries point to (`backend/app/ai/model_catalog.json`, each entry has `facts_verified: false`, `last_verified: null`). Before any production or commercial use, open the linked repository and read the exact licence for the exact checkpoint. Licences can differ between sizes of the same family (for example some Qwen sizes use other terms), and a model that is free to download is not automatically free for every commercial use.

* **Open-source vs open-weight:** these are open-weight models (downloadable weights under a licence). That is not the same as open training data or an OSI "open source AI" definition.
* **Sizes, memory, context length, pricing:** shown as *Unknown, verify before production* because they were not verified here. No benchmark numbers are claimed.
* **Weights are not shipped in the ZIP.** The app never downloads models automatically. Install with `ollama pull <tag>` (see each entry's setup steps).
* **Paid/hosted APIs:** the catalogue lists a generic hosted-API entry only to make the distinction visible. **No hosted provider calls are implemented**; prices and free-tier limits must be taken from the provider and can change.
* **Allow-list:** only entries with `license.reviewed: true` and runtime `ollama` may run (single source of truth for `OPEN_MODELS`).
